## Почему раньше «файла не было»

Лаунчеры лежали в `.ФЛОТ-флот\память\` — папка начинается с точки, то есть скрытая, и внутри вложенной папки. В твоём окне их не было видно, хотя они существовали. Теперь все четыре лежат в корне и видны сразу.

## Что сделано за этот заход

1. **Совет ищет в интернете сам.** Написан `СОВЕТ-ПОИСК.py`: у каждого из 10 руководителей свои поисковые запросы, он читает 4 найденных страницы и отвечает со ссылками `[N]`. Прогон: **10 из 10** файлов, в каждом **5–8 живых ссылок**, текста 1 510–2 949 символов. Затем раунд согласования — каждый видит материалы коллег.
2. Поиск без ключей и без платы: `html.duckduckgo.com` (POST). Честная цифра: после ~30 запросов подряд он отдаёт **403**, поэтому у части руководителей сработали запасные источники — arXiv API, Википедия API, GitHub API (все без ключей). Ссылки настоящие, страницы прочитаны; но в запасном режиме arXiv иногда подсовывает статьи не по теме — это видно в списке источников, фильтр по словам часть мусора срезает.
3. **Материалы совета — в памяти и в боте:** 20 файлов (`L01…L10` + согласования) записаны в память (10 198 записей), пачка отправлена в бота.
4. **Законы:** lawcheck **6 из 7 (86 %)**; открыт только `pc_proof` — запуск на твоём ПК.
5. Всё по-русски: файлы, отчёты, подписи в программах.

## Что осталось за тобой

1. `СЕССИЯ.cmd` — один раз, чтобы забрать входы из браузера (включая Google).
2. `СЛЕЖКА.cmd` — оставить работать.
3. `ПАМЯТЬ.cmd doctor` — это и есть начало `pc_proof`: программа сама запишет лог, sha256 и окружение.
