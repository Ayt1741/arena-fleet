## 4. Совет по мощностям — что получилось честно

Запуск: 10 руководителей, каждый со своими 2 запросами в интернет, чтение до 4 страниц, потом раунд согласования.
Файлы: `.ФЛОТ-флот/state/leaders-capacity/` — 20 файлов, 75 295 символов.

| оценка | сколько файлов |
|---|---|
| годен | **0** |
| частично | 1 |
| брак | **19** |

Причина брака машинная: модель писала рассуждения **по-английски** вместо русского ответа
(например в `L01.md` русских букв 95 против 3 456 английских), а когда основной поиск DuckDuckGo молчал,
запасной GitHub API подсовывал списки `awesome`/`public-apis` — не по теме.
Список оценок лежит в `КАЧЕСТВО.md`, чистилка — `ЧИСТКА-СОВЕТА.py`.

**Что исправляю в следующий прогон (не словами, а кодом):** в совет добавляется проверка качества —
если файл получил «БРАК», запрос повторяется с жёстким требованием «только русский, 5 пунктов, без рассуждений»,
а источники с доменом без отношения к теме отбрасываются до отправки модели.

Поэтому цифры и ссылки выше — из моего собственного проверенного поиска, а не из забракованных файлов совета.
