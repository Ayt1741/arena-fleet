# ХРАНИЛИЩЕ И СТОРОЖ — что поставлено, как проверено

## 1. Склад в Telegram — теперь один на всех агентов

Файл: `.ФЛОТ-флот\память\ХРАНИЛИЩЕ.py`. Работает на Windows и Linux, только стандартная библиотека.
Место в Telegram не кончается, платить не надо.

**Любой агент подключается тремя строками:**

```python
import АГЕНТ
АГЕНТ.работаю('совет')                 # сказал сторожу: я жив, морозить не надо
АГЕНТ.сдать('итог.md', 'совет,итоги')  # залил результат в хранилище
АГЕНТ.взять('итог.md', 'куда/')        # забрал чужой результат
```

`АГЕНТ.py` — обёртка, лежит рядом. Умеет: `что_есть()`, `найти('слово')`, `сколько()`.

**Что проверено прогоном (не обещано):**

| проверка | результат |
|---|---|
| заливка мелкого файла | 1 часть, 112 Б, sha256 `4a049dc8…` |
| заливка 25 МБ | **2 части** по 19 МБ, sha256 `02a717af…` |
| возврат 25 МБ обратно | `sha256_совпал: true`, `cmp` — **байт в байт** |
| поиск по содержимому | запрос «гибридный» нашёл файл по тексту внутри |
| массовая заливка рабочей папки | **286 файлов**, 687 МБ, за один вызов `sync` |
| повторная заливка | 32 новых, 77 «такие же» пропущены по sha256 |

Почему частями: Bot API **отдаёт** файл не больше 20 МБ, поэтому режем по 19 МБ на своей стороне —
иначе скачать обратно большое не получится. Склеиваем по номеру части и сверяем sha256 всего файла.

**Команды в корне рабочей папки:**

| файл | что делает |
|---|---|
| `ХРАНИЛИЩЕ.cmd` | без параметров — что лежит на складе; `put <файл>` — залить; `get <имя>` — достать; `find <слово>` — поиск; `stat` — объём |
| `ЗАЛИТЬ-ВСЁ.cmd` | двойной щелчок — заливает всё новое из рабочей папки (системный кэш пропускает) |

## 2. Сторож — гасит работу после 5 минут тишины

Файл: `.ФЛОТ-флот\память\СТОРОЖ.py`. Задачи и лимит тишины — `.ФЛОТ-флот\сторож\задачи.json`.
Сейчас в нём 4 задачи (`совет`, `слежка`, `флот`, `хранилище`), у каждой лимит **5 минут**.

Как понимает, что задача работает:
1. процесс реально считает (процессорное время **всего дерева**, а не одной оболочки);
2. изменились файлы в папках задачи;
3. агент сам позвал `АГЕНТ.работаю('имя')`.

Тишина 5 минут → процесс **замораживается** (Windows: `NtSuspendProcess`, Linux: `SIGSTOP`).
Он остаётся в памяти, но не делает запросов и **не жжёт лимит**. Первая же активность — оживает.

**Проверено прогоном, лог `ЛОГ-СТОРОЖА.txt`:**

```
00:27:23  запущена задача «тест» (pid 6210, лимит тишины 0.15 мин)
00:27:51  «тест» заморожен: 0.2 мин тишины (лимит 0.15), лимит не тратится
00:27:59  «тест» ожил — есть активность
```

Для ПК настоящий лимит — 5 минут. Проверить самому: `СТОРОЖ.cmd тест` (48 секунд, показывает заморозку и оживление).

**Команды:**

| файл | что делает |
|---|---|
| `СТОРОЖ.cmd` | запустить надзор по расписанию задач |
| `СТОРОЖ.cmd статус` | у кого сколько тишины |
| `СТОРОЖ.cmd отметить <имя>` | сказать «работаю сейчас» |
| `СТОРОЖ.cmd тест` | показать заморозку и оживление вживую |

## 4. Что поставить на каждый ПК (готовое, из интернета)

| программа | зачем | источник |
|---|---|---|
| **Ollama** | локальная модель, 0 ₽ за токен, работает без интернета | ollama.com, MIT |
| **tgfs** / **TAS** | монтируют канал Telegram как обычную папку (FUSE, Linux/macOS) | github.com/davidrencse/telegram-file-storage-system, github.com/liuchzzyy/tas |
| **Teldrive** | сервер-«Google Drive» поверх Telegram, Go, есть REST API для агентов | github.com/tgdrive/teldrive |
| **TeleDrive (senapati484)** | Windows-приложение, показывает Telegram-хранилище как диск, Windows EXE | teledrive.space |

На Linux это даёт прямой доступ «как к папке». На Windows наш `ХРАНИЛИЩЕ.cmd` делает то же самое
командами `put`/`get`/`sync` без установки — и работает прямо сейчас.
