# ФЛОТ НА GITHUB: 20 виртуальных машин, 20 IP — как запустить

Всё готово к вставке. Нужен репозиторий на GitHub (публичный — минуты бесплатны и без лимита).

## Что лежит в пакете
| Файл | Куда положить в репозитории | Зачем |
|---|---|---|
| `worker.py` | `fleet/worker.py` | сама программа боя (вход по cookie, бои, нумерация, уведомления со ссылкой) |
| `workflows/arena-fleet.yml` | `.github/workflows/arena-fleet.yml` | 20 машин разом, у каждой свой IP и своя cookie |

## Шаги (5 минут)
1. Создай репозиторий, например `arena-fleet` (Public).
2. Залей два файла по путям из таблицы выше (Add file → Upload files; путь `.github/workflows/` создаётся сам).
3. Открой **Settings → Secrets and variables → Actions → New repository secret** и добавь:
   - `NTFY_TOPIC` = `arena-captcha-aytsor-4471` (тема уведомлений);
   - `ARENA_COOKIE` = cookie аккаунта №1 (значение `arena-auth-prod-v1`, тот длинный `base64-…`);
   - если аккаунтов несколько — `COOKIE_2`, `COOKIE_3`, … и `ACCOUNT_2`, `ACCOUNT_3`, … (номер секрета = номер машины).
4. Вкладка **Actions → arena-fleet → Run workflow**:
   - `goal` = 12 (сколько боёв на машину),
   - `pause` = 120,
   - `dry` = **1** — первый запуск только для проверки входа, боёв не будет;
   - жми Run.
5. Через ~3 минуты смотри уведомления: по каждой машине придёт «Arena: бой готов» со **ссылкой на диалог** или «Arena: вход не прошёл».
6. Когда вход подтвердится — запусти с `dry` = 0, и бои пойдут.

## Что уже вшито
- **Анти-детект (бесплатно):** подмена `navigator.webdriver`, плагинов, языков, `hardwareConcurrency`, `deviceMemory`, подмена WebGL-вендора, шум в canvas, свой User-Agent, свой экран, свой часовой пояс на каждый запуск. Это то, по чему обычно и палят робота.
- **Cookie режется на два куска** (Chromium не принимает строку длиннее 4096 символов).
- **Нумерация диалогов:** `#01`, `#02`, … — в списке Arena видно как `#01 …`.
- **Ссылка на диалог в уведомлении:** `https://arena.ai/c/<id>` — проверено, открывает именно этот бой.
- **Обновлённая cookie сохраняется** в артефакт `cookies-<машина>.txt`: если сессия «повернулась», берёшь оттуда.

## Три вещи, которые надо знать заранее (это проверяется, а не обсуждается)
1. **Одна cookie = один браузер.** Если одна и та же cookie работает в двух местах, сервер «поворачивает» токен и первый сеанс умирает (проверено: пока бои шли в песочнице, вторая копия получала 401). Поэтому на каждую машину — своя cookie.
2. **Капчу на машине GitHub кликнуть некому.** Раннер без экрана. При капче приходит уведомление «нужна КАПЧА», машина ждёт 5 минут и завершается. Такие бои добиваются здесь, в песочнице, где экран виден и ты жмёшь мышью.
3. **IP у раннеров — датацентровые** (Azure). Cloudflare к ним строже, чем к домашним. Проверяется одним запуском с `dry` = 1: если 20 из 20 дали `api/me = 200`, IP не мешают; если посыпались 429 — добавляем прокси.
